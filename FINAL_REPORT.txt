🚀 FUNCTIONALITY
═══════════════════════════════════════════════════════════════════════════════

How It Works:
  1. User registers with Accept-Language: de header
  2. Middleware captures and sets RegionalContext.locale = 'de'
  3. sendEmailVerificationNotification() is called
  4. VerifyEmailNotification is created with regional context snapshot
  5. Mail::queue() serializes the mailable with context
  6. Queue worker deserializes and restores context via __wakeup()
  7. Email renders with German translations
  8. Email sent to user in German ✅

Supported Queue Modes:
  ✅ Synchronous (QUEUE_CONNECTION=sync)
     • Email processed immediately in request context
     • Good for testing/development

  ✅ Asynchronous Database (QUEUE_CONNECTION=database)
     • Email stored in jobs table
     • Processed by php artisan queue:work
     • Context preserved through serialization

  ✅ Asynchronous Redis (QUEUE_CONNECTION=redis)
     • Email stored in Redis
     • Processed by queue:work with Redis driver
     • Context preserved through serialization

═══════════════════════════════════════════════════════════════════════════════

✅ Automatic Language Detection
   • Reads Accept-Language header from HTTP request
   • Extracts primary language code (e.g., 'de' from 'de-DE,de;q=0.9')
   • Falls back to app.locale if not supported
   • Works across all 6 languages

✅ Context Preservation in Queues
   • RegionalContext snapshot saved when creating mailable
   • Serialized with job when queued
   • Automatically restored via __wakeup() on deserialization
   • Email processed in correct language even by different worker

✅ Template Inheritance
