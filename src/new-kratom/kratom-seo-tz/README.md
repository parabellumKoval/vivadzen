## Как использовать

1. **Сначала** — файл 0 (стратегия) и юр-согласование P0-пунктов из файла 7 §2 (это блокер).
2. Файлы 3–5 — рабочие ТЗ для копирайтера/разработчика (постранично).
3. Файл 6 — для разработчика (внедряемые шаблоны).
4. Файл 7 — план запуска и контроль.

## Ключевой тезис

Рынок CZ-кратома с 12.11.2025 — режим психомодуляционных веществ. Большинство конкурентов нарушают закон в текстах (health-claims) и слабы по E-E-A-T. Стратегия Vivadzen: **топология доверия** — лицензия + COA + 2 каменные точки + юридически чистый экспертный контент + безупречная техника. Это структурное преимущество, которое бюджетом не перебить.
