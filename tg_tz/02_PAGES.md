# 02 — Страницы

## Общий Layout

Каждая страница оборачивается в `<TgLayout>`:

```
┌─────────────────────────┐
│    TgTopBar              │  ← фиксированный хедер (56px)
├─────────────────────────┤
│                          │
│    <slot />              │  ← контент страницы
│                          │
│    padding-bottom: 72px  │  ← отступ под Bottom Tab Bar
└─────────────────────────┘
│    TgBottomNav           │  ← фиксированная навигация (56px + safe-area)
└─────────────────────────┘
```

**TgTopBar** содержит:
- Название страницы (центр) или логотип на главной
- Кнопка «Назад» (левая сторона) — только на внутренних страницах
- Кнопка смены языка (правая сторона) — только на главной и ключевых страницах

## Страница 1: Главная / Каталог

**URL:** `/{region}/{locale}/` и `/{region}/{locale}/{category}`  
**Файл:** `pages/[region]/[locale]/index.vue` + `pages/[region]/[locale]/[category].vue`

### TopBar
- Левый блок: логотип или название магазина
- Правый блок: кнопка смены языка (выпадающий список или bottom sheet)

### Полоска категорий
- Горизонтальный скролл с тегами-пилюлями
- Первый тег: «Все» (все товары)
- Далее: категории из API с названием и количеством товаров в скобках
- Активная категория выделена зелёным (`--color-primary`)
- При переключении — обновляется URL и список товаров ниже

```
[ Все ]  [ Cannabis 9 ]  [ Mushrooms 43 ]  [ CBD ... ]
```

### Заголовок раздела
```
Название категории
N товаров            ← серый подзаголовок
```

### Сетка товаров (2 колонки)
- `grid-template-columns: 1fr 1fr; gap: 12px`
- Пагинация: кнопка «Загрузить ещё» внизу (не бесконечный скролл)
- При загрузке: скелетон из 4 карточек

### Карточка товара → см. [03_COMPONENTS.md](./03_COMPONENTS.md#карточка-товара)

## Страница 2: Товар

**URL:** `/{region}/{locale}/product/{slug}`  
**Файл:** `pages/[region]/[locale]/product/[slug].vue`

### TopBar
- Кнопка «Назад» (к каталогу или категории — через `router.back()`)
- Название страницы: «Товар» или пустое

### Структура страницы (сверху вниз)

**1. Изображение товара**
```
width: 100%
aspect-ratio: 1/1 (квадрат)
background: var(--color-bg-card)
border-radius: 0 (во всю ширину) ИЛИ 16px с отступами
object-fit: contain
padding: 16px
```
Если несколько фото — горизонтальный свайп (слайдер без библиотеки, нативный scroll-snap).  
Точки-индикаторы снизу.

**2. Бейдж SALE** (если есть скидка) — над блоком цены

**3. Название товара**
```
font-size: 18px; font-weight: 700
margin: 16px 16px 4px
```

**4. Цена**
```
Зачёркнутая старая цена (--color-text-muted, line-through)
Актуальная цена крупно (--color-accent, font-size: 22px, font-weight: 800)
```
Если скидки нет — только одна цена.

**5. Переключатель модификаций** (если есть)  
→ см. [03_COMPONENTS.md](./03_COMPONENTS.md#переключатель-модификаций)

**6. Описание товара**
```
font-size: 14px; color: var(--color-text); line-height: 1.6
margin: 16px
```
Длинное описание — обрезается с кнопкой «Читать далее».

**7. Кнопка «Добавить в корзину»**  
Фиксированная снизу (над Bottom Nav) или в конце страницы:
```
position: sticky; bottom: calc(56px + env(safe-area-inset-bottom) + 8px)
margin: 0 16px
```
- Если товар без модификаций → добавить сразу
- Если уже в корзине → показать `-  2  +` счётчик вместо кнопки
- Цвет кнопки: `--color-accent` (оранжевый — «Купить»)

## Страница 3: Оформление заказа

**URL:** `/{region}/{locale}/checkout`  
**Файл:** `pages/[region]/[locale]/checkout.vue`

### TopBar
- Кнопка «Назад»
- Заголовок: «Оформление заказа»

### Структура (сверху вниз)

**1. Краткий список товаров из корзины**  
Свёрнутый блок: иконка корзины + «N товаров на X грн» + стрелка expand.  
При раскрытии — список строк (фото мини + название + кол-во + цена).

**2. Способ доставки**  
Радио-карточки, данные из API (как в `src/front`):
```
┌──────────────────────────────┐
│ ○  Курьер                    │
│    Описание / сроки          │
│    Бесплатно / X грн         │
└──────────────────────────────┘
```

**3. Поля доставки**  
Отображаются в зависимости от выбранного способа доставки.  
Минимальный набор: имя, телефон, адрес/отделение, комментарий (опционально).  
Все поля — из логики `src/front`.

**4. Способ оплаты**  
Радио-карточки, данные из API (как в `src/front`).

**5. Итог**
```
Товары:        X грн
Доставка:      X грн
──────────────────
Итого:         X грн  ← крупно, --color-accent
```

**6. Кнопка «Оформить заказ»** (Accent, full-width)  
Во время отправки — disabled + spinner.

### Валидация
- Inline ошибки под каждым полем
- Кнопка неактивна пока форма не валидна

```
[Вернуться в каталог]          ← Ghost кнопка
```

## Страница 6: Аккаунт / Настройки

**URL:** `/{region}/{locale}/account`  
**Файл:** `pages/[region]/[locale]/account.vue`

### TopBar
- Заголовок: «Аккаунт»

### Структура

**Если пользователь авторизован через Telegram (initData):**
```
Аватар (из Telegram) + Имя + Username
```

**Секция настроек — простой список:**
```
┌──────────────────────────────┐
│  🌍  Язык          Чешский › │
├──────────────────────────────┤
│  📋  История заказов       › │
├──────────────────────────────┤
│  ℹ️   О нас                  › │
└──────────────────────────────┘
```

Смена языка → bottom sheet с вариантами.  
Переключение региона — **отсутствует** (регион берётся из URL, задан в BotFather).

## Страница 7: История заказов

**URL:** `/{region}/{locale}/orders`  
**Файл:** `pages/[region]/[locale]/orders.vue`

### TopBar
- Кнопка «Назад»
- Заголовок: «Мои заказы»

### Список заказов

Если заказов нет — empty state: иконка + «У вас пока нет заказов» + кнопка «Перейти в каталог».

Карточка заказа:
```
┌──────────────────────────────┐
│ #12345          14 мар 2025  │
│ Статус: В обработке  [бейдж] │
│ 3 товара          1 500 грн  │
│                   Подробнее › │
└──────────────────────────────┘
```

Цвет бейджа статуса:
- В обработке → оранжевый
- Отправлен → синий
- Доставлен → зелёный
- Отменён → серый/красный

При нажатии «Подробнее» — bottom sheet или отдельная страница с деталями заказа (список товаров, адрес доставки, способ оплаты, итог).
