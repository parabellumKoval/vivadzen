# Pruvodce — поэтапная реализация

> Раздел `/pruvodce` — wiki-энциклопедия о кратоме на чешском, заточенная под
> сбор информационного SEO-трафика. Контент управляется через админку
> new-kratom-admin. Реализация разбита на фазы, чтобы каждую можно было
> выполнить в одной сессии без перегрузки контекста.

---

## Что уже есть и куда мы это «двигаем»

- `routes/web.php:163` — маршрут `/pruvodce` сейчас рендерит статическую view
  `pages.static.guide`. **Эту view заменяем на динамический раздел.**
- `resources/views/pages/static/guide.blade.php` — старая страница с тремя
  ссылками на коммерческие категории и блоком «дозировка / когда не употреблять».
  **Карточки на /kratom/{цвет} убираем (это коммерческие приземления),
  блок с дозировкой переписываем как нейтральную научную справку — никаких
  призывов к употреблению (см. PHASE-04).**
- Архитектурный шаблон — `lab-batches` (последняя добавленная крупная фича).
  Повторяем тот же путь: миграция → модель → `Admin/*Controller` →
  `routes/admin.php` → страница в `new-kratom-admin/pages/`.

## Как переключаться между фазами в чате

После каждой фазы пиши в новой сессии:

> Реализуй ТЗ из `src/new-kratom/app/docs/pruvodce/PHASE-XX-*.md`.
> Перед началом прочитай `PHASE-00-overview.md` и `README.md` из той же папки.
> Запусти миграции / сидеры если фаза этого требует (см. секцию «Команды» внутри ТЗ).

Каждый ТЗ-файл автономен: содержит контекст, схемы, кодовые скелеты и
команды для проверки. При завершении фазы делается коммит с тегом
`pruvodce-phase-XX`.

## Гайдлайны контента (выжимка из PHASE-00)

1. **Никаких призывов к употреблению, дозировок, «эффектов», «как использовать».**
   Раздел подаётся как энциклопедия: ботаника, химия, история, регулирование,
   методы анализа. Закон 2026 в ЧР делает любую инструктивную риторику
   токсичной для домена.
2. **Никакой конкуренции с коммерческими страницами.** Если ключ заточен на
   покупку (`koupit`, `cena`, `e-shop`, `bily/zeleny/cerveny kratom`) — он
   принадлежит `/kratom/*` taxonomy, а не wiki. Wiki берёт только
   информационный intent.
3. **Структурированно, со ссылками внутри раздела.** Каждая статья — H1 + 4–8
   разделов H2, FAQ-блок в конце, 3–6 ссылок на родственные wiki-статьи
   («Související články»). Без ссылок на /kratom/* кроме одной финальной
   неагрессивной плашки.
4. **Glosář** — статьи терминологии (mitragynin, alkaloid, COA, mesh) являются
   «центрами» перелинковки: на них ссылаются десятки других статей.

## Стек, на котором всё работает

- **Backend:** Laravel 11, MySQL/MariaDB, Sanctum для admin API
- **Admin:** Nuxt 3, TipTap 3 (`AdminRichEditor.vue`), AdminMediaPicker
- **Public:** Blade + SCSS (компоненты `x-layouts.app`, `x-static.hero`,
  `x-ui.breadcrumbs`), prose-стили из `_static.scss`
- **i18n:** Locale::url() для мультиязычных URL, дефолт `cs`

## Не путать

- `/sarze/{batch}` — это COA партий из `lab_batches` (другая фича).
- `/forum` — пользовательские обсуждения, тоже отдельная фича.
- `/pruvodce` — наша новая wiki, чисто редакторская.
