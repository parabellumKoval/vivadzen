## 1. ПРИОРИТИЗАЦИЯ (принцип)

Порядок = (юр. безопасность) → (trust-фундамент, без него YMYL не растёт) → (коммерческое ядро) → (контент-хаб) → (масштабирование). Сначала то, что (а) обязательно по закону и (б) даёт Google сигнал доверия — иначе коммерческие страницы не ранжируются в YMYL.

## 4. KPI И МЕТРИКИ

### Ведущие (leading, проверяем еженедельно/ежемесячно)
- Кол-во проиндексированных целевых URL (GSC Coverage) vs план.
- Покрытие ядра: % ключей из файла 1 в топ-10 / топ-3 (Collabim/Marketing Miner, гео CZ).
- Доля «trust»- и «legislativ»-кластеров в топ-10 (наш дифференциатор).
- Rich Results: % страниц с валидной schema (Product/FAQ/LocalBusiness/Breadcrumb).
- CWV: % URL в «Good» (mobile).
- Внутр. перелинковка: 0 orphan-страниц, средняя глубина ≤ 3.
- Кол-во реферальных доменов на pillar/legislativ/jak-poznat (link-bait работает?).

### Итоговые (lagging, мес./квартал)
- Органический трафик (нерекламный) — рост MoM/QoQ.
- Органические транзакции/выручка, конверсия органики, доля local (Praha/osobní odběr).
- Видимость по брендовым и небрендовым кластерам.
- Заявки lead-формы placeholder (потенциал к моменту лицензии).
- Доля трафика на trust-страницы (косвенный сигнал доверия аудитории).

### Ориентиры (реалистичные, YMYL — рост не мгновенный)
- Мес. 1–2: индексация фундамента, брендовый трафик стабилен, технических ошибок → 0.
- Мес. 3–4: вход в топ-10 по средне-частотным «kratom Praha», «{cvet} kratom», legislativ-ключам; первые внешние ссылки на legislativ-pillar.
- Мес. 6: топ-10 по части ВЧ («kratom prášek», «kratom koupit»), стабильный рост органики, placeholder копят вес.
- Мес. 9–12: топ-3 по trust/legislativ/local кластерам, заметная доля небрендовой органики, готовность placeholder монетизировать при лицензии.

> Честно: точные числа трафика прогнозировать без данных GSC/частотностей нельзя — это будет «фальшь». KPI заданы как измеримые цели и контрольные точки, не как обещание X посетителей.

## 5. ЛИНКБИЛДИНГ И OFF-PAGE (для обгона бюджетных конкурентов)

YMYL-домен растёт на доверии + ссылках с авторитетных тематически близких источников. Стратегия — «зарабатывать ссылки контентом», не покупать сетки (риск для YMYL).

- **Link-bait активы:** legislativ-pillar (`kratom-zakon-2026`), «jak poznat kvalitní kratom» (+ скачиваемый чек-лист PDF), risk-страница. Их цитируют форумы/медиа/блоги, потому что они нейтральны и полезны.
- **Digital PR:** короткие экспертные комментарии для медиа при новостях регуляции (вы — licencovaný prodejce → авторитетный комментатор). Каждая новость о PML = повод для упоминания/ссылки.
- **Локальные сигналы:** Google Business Profile ×2 (заполнить полностью, фото, посты, отзывы), чешские каталоги (Firmy.cz/Seznam, Heuréka, Zboží.cz — для CZ это и trust, и трафик).
- **Тематические упоминания:** профильные чешские сообщества/обзоры — участие экспертно, без спама.
- **Brand SERP:** заполнить Knowledge Panel-сигналы (Organization schema, sameAs, консистентный NAP, Wikidata-сущность бренда опц.).
- **Внутренний линкинг** (файл 2) — самый дешёвый и контролируемый «линкбилдинг», использовать на 100%.
- ❌ Не делать: PBN, массовая закупка, link-схемы — для YMYL/веществ это прямой риск ручных санкций.

## 6. РИСКИ И ОГРАНИЧЕНИЯ (честно)

- **Юридический (главный):** запреты health-claims, режим листинга нелицензированных товаров, §33e — финал за вашим юристом по zák. č. 167/1998 Sb. Я заложил наиболее защищённую архитектуру, но не даю юр-гарантию.
- **Регуляторика меняется:** legislativ-pillar и связанные страницы — «живые», обновлять немедленно при изменениях; иначе риск устаревшей/некорректной инфы (минус E-E-A-T и юр. риск).
- **Региональные doorway-страницы:** соблазн наделать «kratom Brno/Ostrava/...» тонких лендингов — это doorway-паттерн и риск алгоритм/ручной санкции. Делать только с реально уникальным контентом и доказанным спросом (Фаза 4), иначе 1 сильная «Doručení po celé ČR» + Прага-локал.
- **Age-gate:** неверная реализация (редирект/скрытие) обнулит индексацию — строго по файлу 6 §6.
- **Fake-отзывы/schema:** Review/AggregateRating только реальные — фейки = ручная санкция + репутация.
- **Каннибализация:** при росте числа страниц следить за пересечениями (файл 1 §11, файл 2 §5) — ежеквартальный аудит.
- **Платёжные/Merchant ограничения:** часть рекламных/Merchant каналов ограничивает PML — органика тем ценнее, но это вне SEO-скоупа (отметить для маркетинга).

## 7. ДОПОЛНИТЕЛЬНЫЕ ИДЕИ (сверх стандарта — для отрыва от конкурентов)

1. **«COA-эксплорер»** — интерактивный раздел: выбираешь товар → видишь таблицу значений последней šarже + историю šarží. Уникальный E-E-A-T/конверсионный актив, которого нет ни у кого в CZ. Каждая šarже = индексируемая страница (long-tail «{produkt} laboratorní test»).
2. **«Stav legislativy» виджет/баннер** на legislativ-pillar — дата последнего обновления + «co je aktuální». Сигнал свежести для Google и доверия для юзера.
3. **Lead-сбор на placeholder** — «Upozornit při naskladnění» с double opt-in: к моменту лицензии у вас тёплая база на 15 товаров → мгновенная конверсия + поведенческие сигналы.
4. **Odborný garant как публичная фигура** — реальное лицо с bio/фото на /o-nas и в `author` всех гайдов. Самый сильный E-E-A-T-рычаг, который промис-конкуренты не имеют.
5. **Скачиваемый чек-лист «Jak poznat licencovaný kratom e-shop» (PDF)** — лид-магнит + ссылочный магнит (его будут шарить).
6. **Glossary/мини-вики граф** — `/encyklopedie/*` с плотной взаимной перелинковкой по сущностям (Mitragyna, mitragynin, барвы, штаммы) → тематический авторитет домена по entity-SEO.
7. **FAQ-снипет-стратегия** — короткие 40–55-словные ответы под H1 на инфо-страницах → захват featured snippets по «je kratom legální», «co je COA», «od kolika let kratom».
8. **Seznam.cz оптимизация** — отдельная проверка под Seznam (CZ-доля поиска ощутима, конкуренты часто игнорируют → дешёвый трафик).
9. **«Proč u nás nenajdete sliby o účincích»** — превратить комплаенс в маркетинг доверия: отдельный блок/страница, объясняющая честность vs «маркетинговые сказки» конкурентов. Уникальное позиционирование.
10. **Структурированные сравнения форм/штаммов** (таблицы, фактология) — выигрывают по «{X} vs {Y}» long-tail, которые конкуренты делают текстом-портянкой.

## 8. ИТОГ — ПОЧЕМУ ЭТО ОБГОНИТ БЮДЖЕТНЫХ КОНКУРЕНТОВ

Конкуренты вкладывают бюджет в объём контента, который (а) юридически нарушает режим PML и (б) для Google по YMYL — низкодоверенный. Vivadzen строит структурное преимущество, которое бюджетом не купить за месяц:

1. **Юр. чистота** = устойчивость (не обнулится при следующем ужесточении).
2. **Реальная лицензия + 2 каменные точки + COA** = E-E-A-T-фундамент, физически недоступный «домашним» конкурентам.
3. **Тематический граф** (коммерция ↔ pillar ↔ энц. ↔ legislativ ↔ trust) с дисциплинированной перелинковкой = семантический авторитет.
4. **Комплаенс как УТП** = уникальное позиционирование доверия.
5. **Безупречная техника** (age-gate без вреда индексации, schema, CWV) = там, где конкуренты массово ошибаются.

Это игра «в долгую и по правилам», которая в YMYL выигрывает у «в лоб и грязно».
